# Мой тамагочи

Виртуальный ИИ-компаньон: комнаты, потребности, анимации и чат с Cloudflare Workers AI.

## Структура
- `index.html` — веб-приложение.
- `worker.js` — Cloudflare Worker для ответов ИИ.
- `wrangler.toml` — конфигурация Wrangler.
- `assets/char/` — изображения персонажа.
- `assets/rooms/` — изображения комнат.

Изображения добавим отдельно, когда будут готовы файлы. Пока приложение использует встроенные заглушки.
